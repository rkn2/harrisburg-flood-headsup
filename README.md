# Harrisburg Flood Heads-Up (mockup)

Interactive concept mockup for a flood briefing tool for the City of Harrisburg, PA, prepared by a Penn State team (Cheng, Clark, Gervais, Napolitano, Smithwick). It is not an operational tool and is not endorsed by the City of Harrisburg. The heavy-rain view is pending review by Capital Region Water.

View it at https://rkn2.github.io/harrisburg-flood-headsup/

Data sources are listed in the page footer. The page is built from a private working repo; this repo holds only the published page.
